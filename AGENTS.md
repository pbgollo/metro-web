# Metro Web

Aplicação web de passageiros do **MetroIsJustABus**.

## Especificação

A especificação do sistema (enunciado v1.0, 2026-09-29) está em [`docs/spec/metro-is-just-a-bus.md`](docs/spec/metro-is-just-a-bus.md). O PDF original está na mesma pasta. Há uma cópia igual em `metro-core/docs/spec/`; ao atualizar o enunciado, atualiza as duas.

Antes de alterar fluxos de passageiro, contratos com a API ou comportamento visível, lê esse ficheiro. Não inventes requisitos que o contradigam. Esta aplicação é um componente do sistema distribuído; notificações e outros serviços de apoio vivem fora deste repositório.
